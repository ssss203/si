# 肆 · 桌面宠物 Agent

![肆](docs/pet.jpg)

一句话：一只住在 Windows 桌面上的毒舌桌宠“肆”，大脑是 Pi agent 运行时，所以它会聊天、会记事、还能改自己的代码。

## 怎么装上它

### 方式一：下载安装包（推荐，不用懂技术）

1. 打开 [Releases](https://github.com/ssss203/si/releases)，下载 **`si-pet-1.0.0-x64-setup.exe`**
   （不想安装的话，可以下 `si-pet-1.0.0-x64-portable.exe`，免安装双击即用）
2. 双击安装，打开「肆」
3. 点桌宠 → 打开通话窗口 → ⚙️ → 填入你的 DeepSeek API Key → 跟它说话

DeepSeek API Key 在 https://platform.deepseek.com 注册后创建。**记得充一点余额** —— key 本身不免费，几分钱一次对话。

⚠️ 程序没有代码签名，Windows 可能提示“未知发布者”，选“仍要运行”即可。

⚠️ 杀毒软件（火绒 / 360 等）可能误报 —— Electron 程序常被误报，请选择“允许”。

### 方式二：从源码运行（给想改它的人）

（Node ≥ 22.19；目前只在 Windows 验证过）

```bash
git clone https://github.com/ssss203/si.git
cd si/pet-si/pet-app
npm install
npm run dev
```

国内网络如果 `npm install` 卡在下载 Electron，先运行一次：
`npm config set ELECTRON_MIRROR https://npmmirror.com/mirrors/electron/`

自己打包 Windows 安装包：`npm run dist:win`（产物在 `pet-app/release/`）

第一次启动后：打开通话窗口 → ⚙️ 填 DeepSeek API Key → 跟它说话。

## 它能干什么

- 聊天（逐字流式）+ 固定人设（它自己可以改自己的性格，`role-card.json` 里也可以改它性格）
- 记得住（重启不失忆，记忆存在你自己电脑上）
- 能读文件、搜内容、列目录
- 能改自己的代码，**改坏了一键撤回**（改前自动存档）
- 能自己动：播动画、主动说话、安排提醒（每小时最多 6 次，可关）
- 偶尔“瞥一眼”你在干嘛（只传粗分类标签，不涉及隐私、不传标题原文，默认关）

## 它现在还不能干什么

- **还没有自动更新**（下一个版本做：启动时检查新版 → 提示更新）
- macOS 没实现（“看你在干嘛”目前只在 Windows 生效）
- 代码没有签名（所以安装时会看到“未知发布者”提示）
- 目前只支持 DeepSeek 的 API Key（作者是小白，还在学怎么接别的）

## 安全边界

- 它想改你项目目录以外的文件，**会弹窗问你**（仅这次 / 这个目录以后都允许 / 拒绝；60 秒不点算拒绝）
- `.env`、`.git/` 等 5 类文件**永远不许碰**（授权也解不开）
- 它自己写的“技能”默认**不生效**，要你在面板里点启用
- 每次改文件前自动存档，撤回**只还原它动过的文件**，不碰你其它未提交改动
- 目前**没有开放 bash**（不能执行任意命令）：它的能力都是一个个显式化的工具（读文件、跑自检、改文件前存档…）。以后可能会加，加的时候会配命令白名单 + 单独确认。
