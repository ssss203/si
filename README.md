# 肆 · 桌面宠物 Agent

![肆](docs/pet.jpg)

一句话：一只住在 Windows 桌面上的毒舌桌宠“肆”，大脑是 Pi agent 运行时，所以它会聊天、会记事、还能改自己的代码。

## 它能干什么

- 聊天（逐字流式）+ 固定人设（它自己可以改自己的性格，`role-card.json` 里也可以改它性格）
- 记得住（重启不失忆，记忆存在你自己电脑上）
- 能读文件、搜内容、列目录
- 能改自己的代码，**改坏了一键撤回**（改前自动存档）
- 能自己动：播动画、主动说话、安排提醒（每小时最多 6 次，可关）
- 偶尔“瞥一眼”你在干嘛（只传粗分类标签，不涉及隐私、不传标题原文，默认关）

## 怎么跑起来

（Node ≥ 22.19；目前只在 Windows 验证过）

```bash
git clone https://github.com/ssss203/si.git
cd si/pet-si/pet-app
npm install
npm run dev
```

第一次启动后：打开通话窗口 → ⚙️ 填 DeepSeek API Key → 跟它说话。

## 它现在还不能干什么

- 打包成 exe 还不行（Forge 打包会静默不产出任何文件，还在查）
- macOS 没实现（“看你在干嘛”目前只在 Windows 生效）
- 没有安装向导、没有自动更新、代码没签名
- 目前只支持 DeepSeek 的 API Key（作者是小白，还在学怎么接别的）

## 安全边界

- 它想改你项目目录以外的文件，**会弹窗问你**（仅这次 / 这个目录以后都允许 / 拒绝；60 秒不点算拒绝）
- `.env`、`.git/` 等 5 类文件**永远不许碰**（授权也解不开）
- 它自己写的“技能”默认**不生效**，要你在面板里点启用
- 每次改文件前自动存档，撤回**只还原它动过的文件**，不碰你其它未提交改动
