# 肆 · 桌面宠物 Agent

![肆](docs/pet.jpg)

一句话：一只住在 Windows 桌面上的毒舌桌宠“肆”，大脑是 Pi agent 运行时，所以它会聊天、会记事、还能改自己的代码。

## 怎么装上它

（Node ≥ 22.19；目前只在 Windows 验证过。**不需要懂编程**，照着做就行。）

**1. 装 Node.js** —— 去 https://nodejs.org 下载 **LTS 版**，一路“下一步”（安装时保持勾选 `Add to PATH`）

**2. 下载代码** —— 在本页面点绿色 **Code** → **Download ZIP**，解压到任意位置
（装了 git 也可以：`git clone https://github.com/ssss203/si.git`）

**3. 打开终端** —— 进入解压出来的 `si\pet-si\pet-app` 文件夹，在地址栏输入 `cmd` 回车

**4. 运行两条命令**

```bash
npm install
npm run dev
```

第一次会比较慢（要下载 Electron，约 100MB）。国内网络如果卡住，先单独运行一次：
`npm config set ELECTRON_MIRROR https://npmmirror.com/mirrors/electron/`

**5. 填 Key** —— 桌宠出现后点它 → 打开通话窗口 → ⚙️ → 填入你的 DeepSeek API Key → 跟它说话
（Key 在 https://platform.deepseek.com 注册后创建。**记得充一点余额**，key 本身不免费，几分钱一次对话）

**6. ⚠️ 那个命令行窗口不要关** —— 关了桌宠就会退出

遇到杀毒软件拦截（火绒 / 360 等）请选择“允许” —— Electron 程序常被误报。

## 它能干什么

- 聊天（逐字流式）+ 固定人设（它自己可以改自己的性格，`role-card.json` 里也可以改它性格）
- 记得住（重启不失忆，记忆存在你自己电脑上）
- 能读文件、搜内容、列目录
- 能**改文件、新建文件**，改坏了**一键撤回**（改前自动存档）
- 能自己动：播动画、主动说话、安排提醒（每小时最多 6 次，可关）
- 偶尔“瞥一眼”你在干嘛（只传粗分类标签，不涉及隐私、不传标题原文，默认关）
- 每周检查一次有没有新版本，有的话提醒你

## 它现在还不能干什么

- **没有安装包** —— 目前只能按上面“从源码运行”的方式装（要装一次 Node）
- **还没有自动更新**（以后再说）
- macOS 没实现（“看你在干嘛”目前只在 Windows 生效）
- 目前只支持 DeepSeek 的 API Key（作者还在学怎么接别的）

## 安全边界

- 它想改你项目目录以外的文件，**会弹窗问你**（仅这次 / 这个目录以后都允许 / 拒绝；60 秒不点算拒绝）
- `.env`、`.git/` 等 5 类文件**永远不许碰**（授权也解不开）
- 它自己写的“技能”默认**不生效**，要你在面板里点启用
- 每次改文件前自动存档，撤回**只还原它动过的文件**，不碰你其它未提交改动
- 目前**没有开放 bash**（不能执行任意命令）：它的能力都是一个个显式化的工具（读文件、跑自检、改文件前存档…）。以后可能会加，加的时候会配命令白名单 + 单独确认。
